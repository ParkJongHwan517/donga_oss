# Sprint 지표 분석

## Cycle Time

FIT Sprint 1 이슈의 생성 시점부터 완료 시점까지의 시간을 계산하였다.

- 완료 이슈: 6개
- 총 Cycle Time: 155초
- 평균 Cycle Time: 약 25.8초

Sprint 1의 작업은 실제 작업 완료 후 GitHub Issue로 등록하였기 때문에,
측정된 Cycle Time은 실제 개발 소요시간을 의미하지 않는다.
Sprint 2부터는 이슈 생성 및 상태 변경 시점을 기준으로 측정할 예정이다.

## Velocity

FIT Sprint 1에서 계획한 6개의 이슈를 모두 완료하였다.

- 계획 이슈: 6개
- 완료 이슈: 6개
- Velocity: 6 issues/sprint
- 완료율: 100%

## Burndown

FIT Sprint 1은 총 6개의 작업으로 구성되었으며 최종 잔여 이슈는 0개이다.

- 시작 작업: 6개
- 완료 작업: 6개
- 잔여 작업: 0개

Sprint 1 작업은 GitHub Issue에 사후 등록하여 일별 Burndown 추이를 측정하기 어렵다.
Sprint 2부터는 이슈 상태 변경 기록을 이용하여 잔여 작업량 변화를 추적할 예정이다.
