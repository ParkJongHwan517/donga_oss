# Week 1-2 상품 데이터 확보 가능성 검증

### 검증 목적

FIT의 핵심 기능을 구현하기 위해 필요한 상품 데이터를 공식적으로 제공되는 API를 통해 합법적이고 지속적으로 확보할 수 있는지 검증한다.

특히 초기 MVP에서 다루는 바지의 경우 다음과 같은 데이터가 필요하다.

- 상품명
- 브랜드
- 가격
- 상품 이미지
- 상품 판매 URL
- 사이즈 옵션( S / M / L 등)
- 사이즈별 허리
- 허벅지
- 밑위
- 및단
- 총장
