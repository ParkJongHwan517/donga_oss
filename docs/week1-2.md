# Week 1-2 상품 데이터 확보 가능성 검증

### 검증 목적

FIT의 핵심 기능을 구현하기 위해 필요한 상품 데이터를 공식적으로 제공되는 API를 통해 합법적이고 지속적으로 확보할 수 있는지 검증한다.

특히 초기 MVP에서 다루는 바지의 경우 다음과 같은 데이터가 필요하다.

- 상품명
- 브랜드
- 가격
- 상품 이미지
- 상품 판매 URL
- 사이즈 옵션( S / M / L 등)
- 사이즈별 허리
- 허벅지
- 밑위
- 및단
- 총장

### 공식 데이터 제공 방법 조사

여러 쇼핑몰 및 쇼핑몰 연동 서비스를 조사한 결과 상품명, 가격, 이미지, 옵션 등의 일반적인 상품 데이터는 공식 API를 통해 제공되는 경우가 있었다.

하지만 FIT에서 필요한 허리, 허벅지, 밑위, 밑단, 총장과 같은 의류 실측값을 외부 서비스에 직접 제공하는 API는 찾기 어려웠다.

도매꾹은 Open API를 제공하고 있어 실제 상품 데이터를 이용한 테스트가 가능했고, 따라서 도매꾹 Open API를 이용하여 데이터 확보 가능성을 직접 확인했다.

### 도매꾹 Open API 테스트

도매꾹 Open API의 상품 상세정보 조회 기능을 이용하여 실제 판매 중인 바지 및 남성 의류 상품 6개를 테스트 하였다.

테스트 결과 6개 상품 모두에서 다음 정보를 가져올 수 있었다.

- 상품번호
- 상품명
- 카테고리
- 상품 옵션
- 상세페이지 이미지 주소

사이즈 옵션의 경우 상품에 따라
M(28), L(30), XL(32)와 같이 제공되는 경우도 있었으며, 색상과 사이즈가 함께 옵션으로 제공되는 경우도 있었다.

하지만 허리, 허벅지, 밑위, 밑단, 총장등에 대한 실측값은 API에서 별도의 데이터로 직접 제공되지는 않았다.

### 상세 이미지의 사이즈표 확인

API에서 실측값을 직접 제공하지는 않았지만 상품 상세페이지에 사용되는 이미지 주소를 가져올 수 있었다. 사이즈표가 포함되어 있는 상품이 있었기에 API를 통해 상세 이미지를 가져온 뒤 이미지 속 사이즈표를 읽는 방법을 추가로 테스트했다.

6개 상품을 대상으로 확인한 결과 5개 상품에서 사이즈표를 찾을 수 있었다.

첫 번째 테스트 상품에서는 사이즈별로 허리, 허벅지, 엉덩이,
밑단, 총장 등의 값이 상세 이미지에 표시되어 있었다.

따라서 API에서 실측값을 직접 제공하지 않더라도
API를 통해 얻은 상세 이미지의 사이즈표를 이용하면
FIT에서 사용할 실측 데이터에 접근할 수 있다는 것을 확인하였다.

### 검증 결과

이번 테스트를 통해 상품 데이터 자체를 확보할 방법이 없는 것은 아니라는 것을 확인하였다.

도매꾹 Open API를 이용하면 상품 기본정보와 사이즈 옵션, 상세 이미지를 가져올 수 있었고, 테스트한 6개 상품 중 5개 상품의 상세 이미지에서 사이즈표도 확인할 수 있었다.

다만 이미지에서 값을 추출하는 과정에서 오차가 발생할 수 있다.

따라서 초기 MVP에서는 다음과 같은 방식으로 상품 데이터를 구축하는 것을 고려한다.

도매꾹 Open API

- 실제 상품 확보
- 상세 이미지
- 사이즈표 추출 및 검수
- FIT 비교 기능 검증
