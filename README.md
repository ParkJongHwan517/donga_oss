# FIT

> **Shop by your fit.**
> 내가 가장 잘 맞는 옷을 기준으로 새로운 옷을 비교해주는 개인 맞춤형 패션 서비스

---

## 프로젝트명

**FIT**

사용자가 이미 가지고 있는 잘맞는 옷인 **Reference outFit**을 기준으로 새로운 상품의 정보를 비교하여, 해당 상품이 자신에게 맞는 FIT일지 판단할 수 있도록 도와주는 서비스입니다.

단순히 "M 사이즈를 추천합니다."라고 알려주는 것이 아니라,

> 이 상품 M은 내가 좋아하는 바지보다 허리는 1CM크고, 기장은 4CM짧습니다."

처럼 사용자가 이미 알고 있는 자신의 옷을 기준으로 새로운 상품의 핏을 이해할 수 있도록 하는 것이 핵심입니다.

---

## 문제 정의

온라인에서 옷을 구매할 때 소비자는 **상품의 사이즈 정보는 확인할 수 있지만, 해당 사이즈가 자신에게 어떻게 맞을지는 쉽게 판단하기 어렵습니다.**

현재 온라인 쇼핑몰에서 제공하는 정보는 다음과 같습니다.

- S/M/L 등의 사이즈
- 상품별 실측 정보
- 모델의 키 / 몸무게 / 착용 사이즈
- 리뷰어의 키 / 몸무게
- '작아요 / 잘 맞아요 / 커요' 등의 리뷰

하지만 다음과 같은 문제가 있습니다.

### 1. 같은 사이즈라도 상품마다 실제 크기가 다름

같은 브랜드의 M사이즈라도 상품마다 허리, 총장, 허벅지, 어깨 등의 실측이 다릅니다.

따라서 평소 M사이즈를 입는다는 정보만으로 새로운 상품의 M사이즈가 자신에게 잘 맞을지 판단이 어렵습니다.

### 2. 키와 몸무게만으로 원하는 핏을 판단하기 어려움

같은 키와 몸무게를 가진 사람이라도 신체 비율, 원하는 핏이 다릅니다.

예를 들어, 한 사용자는 와이드 핏을 선호하지만, 다른 사용자는 스트레이트핏을 선호할 수 있습니다.
또한, 키 / 몸무게 같은 사람의 리뷰만 보고 옷을 샀는데 신체 비율이 달라 총장이 짧을 수 있습니다.

### 3. 내가 좋아하는 옷 핏이랑 같은지 판단하기 어려움

대부분의 사람은 자신의 정확한 신체 치수를 모르더라도

> 이 옷은 나한테 정말 잘 맞는다.

라는 사실을 알고 있습니다.

FIT은 이러한 옷을 **Reference outFit**으로 활용하여 새로운 상품과 직접 비교합니다.

## 핵심 문제

> **온라인 패션 쇼핑에서는 상품의 사이즈/리뷰와 사용자가 실제로 원하는 착용감 사이에 정보의 공백이 존재합니다.**

FIT은 사용자가 이미 가지고 있는 잘 맞는 옷을 기준으로 이 공백을 줄이는 것을 목표로 합니다.

## 핵심 기능

### 1. Reference outFit 등록

사용자가 현재 가지고 있는 옷 중 가장 잘 맞거나 좋아하는 옷을 **기준 옷(Reference outFit)** 으로 등록합니다.

###### 바지의 경우

| 측정 항목 | 실측  |
| --------- | ----- |
| 허리      | 38cm  |
| 총장      | 105cm |
| 허벅지    | 30cm  |
| 밑위      | 30cm  |
| 밑단      | 22cm  |

사용자는 해당 옷의 핏에 대한 선호도도 함께 기록할 수 있습니다.

---

### 2. 개인 맞춤 상품 탐색 및 비교

상품을 선택하면 자신의 **Reference Outfit**과 얼마나 다른지도 함께 제공합니다.

#### 검색조건 예시

> "내 최애 슬랙스와 비슷하게 맞는데 조금 더 와이드하고, 기장은 조금 더 길면서 검정색이고 7만 원 이하인 바지"

#### 상품 선택 시 예시

- 허리: +0.5cm -> 거의 비슷함
- 허벅지: +1.5cm -> 조금 더 여유로움
- 총장: +1cm -> 조금 더 김
- 색상: 블랙
- 가격: 49,000원

> **FIT**은 사용자가 이해하기 쉬운 결과로 변환합니다.

###### 초기에는 _**상품보러가기**_ 를 통해 외부 판매처의 실제 상품페이지로 넘어갈 수 있습니다.

### 3. 구매한 상품에 대한 Fit review

상품 구매 후에는 실제 착용 결과를 기록할 수 있습니다.

#### Fit review 예시

- 허리: 좋음
- 허벅지: 좋음
- 기장: 짧음
- 전체 만족도: 보통
- 구매결과: 반품

이러한 **Fit review**는 향후 사용자의 **Fit profile**과 Fit Engine을 개선하는 데이터로 활용됩니다.
